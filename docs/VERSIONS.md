# Pinned versions

Everything the macOS build depends on, what it is pinned to, and why. Keep this in
step with the scripts that enforce it; a pin written here and not enforced in a
script is a wish, not a pin.

| Component | Pin | Why | Enforced by |
|---|---|---|---|
| Engine | upstream Recoil release tag **2026.09.02** + this repository's macOS layer | BAR's next engine: its Engine Test channel (BYAR-Chobby `dist_cfg/config.json`, `manual-*-test-engine`) since 2026-10-27. Production (`manual-linux`/`manual-win`) is still 2026.07.04, so until BAR moves, this build can replay and play only Engine Test games. Moved ahead of production on 2026-11-09 by decision: releases from this repository target the engine BAR is moving to (`docs/MAINTENANCE.md`) | `rts/build/cmake/ConfigureVersion.cmake` (nearest numeric tag); `scripts/build-engine.sh` refuses to build without upstream tags |
| streflop libm lane | "submodule" lane: dbl-64 objects recompiled with gcc and swapped in | Fleet builds use gcc's `-fsingle-precision-constant`, which clang lacks | `scripts/gcc-dbl64-swap.sh`; libm parity gate (9/9 vs `testkit/libm-refs/double-fn-vm26.txt`) in `scripts/build-engine.sh` |
| gcc (libm swap only) | Homebrew **`gcc@15`** (`/opt/homebrew/bin/g++-15`) | The fleet reference hashes were generated with gcc 15; Homebrew's `gcc` is now 16 | `scripts/gcc-dbl64-swap.sh` (fails naming gcc@15); installed by `scripts/build-mesa-kk.sh` |
| Mesa driver | **mesa-26.3.0-rc3** (`90a959ebba9d`, was `8f272b1fe18e` 26.2.0-devel) + the 9 `patches/mesa/*.patch` | The Zink + KosmicKrisp stack the bundle ships, built from pinned upstream source. Re-pinned 2026-11-08: 117 KosmicKrisp commits newer; of the 13 old patches, 3 were dropped as upstream (renderpass tracking; the vertex-input pipeline fix is 6abefa5177e; fast-math-with-safe-ops replaces the KK_MATH_MODE knob), 1 as obsolete (cross-queue pre_gfx ordering: rc3 uses one command buffer per VkCommandBuffer), 3 ported, 6 apply as they were. Move to 26.3.0 final when tagged | `scripts/build-mesa-kk.sh` provenance stamp (commit, patch hashes, SPIRV tag, macOS target, driver deps); `scripts/gpu-smoke.sh` checks it renders |
| Driver runtime deps | Vulkan-Headers, Vulkan-Loader, SPIRV-Headers, SPIRV-Tools at `vulkan-sdk-1.4.363.0`; zstd 1.5.7; sha256-pinned | SPIRV-Tools and zstd linked statically into the driver (it has no non-system dependency); the loader is a dylib because zink `dlopen()`s it. Homebrew's LLVM 19 is linked statically at build time only | `scripts/build-driver-deps.sh` |
| SPIRV-LLVM-Translator | `v19.1.7` | Matched to `llvm@19` for Mesa's CLC step | `scripts/build-mesa-kk.sh` |
| LLVM (Mesa build only) | Homebrew `llvm@19` | Later LLVM cannot link Mesa's KosmicKrisp CLC step | `scripts/build-mesa-kk.sh` |
| libclc | Homebrew's when it serves the pinned Mesa, else built from LLVM 19.1.7 | Homebrew libclc 23 ships no `libclc.pc` and no mesa3d targets | `scripts/build-libclc.sh` |
| SDL2 | **2.32.10**, always built from the release tarball (sha256-pinned) | Homebrew's `sdl2` is now `sdl2-compat`, an SDL2 shim over SDL3 that `dlopen()`s SDL3 at runtime: the bundle would ship without SDL3 and fail to start, and the windowing/input backend would change underneath the port's SDL workarounds. 2.32.10 is what v0.13 shipped | `scripts/build-sdl2.sh` |
| Static libraries (image, archive, audio decoding) | the [spring-static-libs](https://github.com/beyond-all-reason/spring-static-libs) set, same versions, sha256 pins and feature flags as upstream's Linux release: zlib 1.3.1, libpng 1.6.50, giflib 5.2.2, jpeg 9f, libtiff 4.7.0 (no lzma/jbig), DevIL 1.8.0 (IL/ILU/ILUT; png, jpeg, tiff, gif), libogg 1.3.6, libvorbis 1.3.7, xz 5.8.1, minizip-ng 4.0.10 (compat, zlib backend) | The fleet's Linux engine links exactly these statically; matching them gives macOS the same decoders and archive code as Linux and Windows instead of whatever Homebrew bottles hold. Two macOS-only adjustments: DevIL is compiled with `TRUE`/`FALSE` predefined (clang has no `-fpermissive`), minizip-ng with `MZ_LIBCOMP=OFF` (Linux's zlib path, not Apple's libcompression) | `scripts/build-static-libs.sh`; linked with `PREFER_STATIC_LIBS`, `pkg-config --static`, Homebrew prefixes ignored (`scripts/build-engine.sh`) |
| freetype, fontconfig, OpenAL | freetype **2.15.0** (zlib + png; no bzip2/brotli/harfbuzz), fontconfig **2.18.3**, openal-soft **1.25.2** (CoreAudio), sha256-pinned upstream tarballs, built as dylibs | Linux takes these from the OS; macOS has no system copy. Apple's OpenAL.framework lacks alext/efx. On macOS the engine hands fontconfig the system font directories explicitly, as it does on Windows (`CFontTexture.cpp`), so no compiled-in config path is consulted | `scripts/build-shared-libs.sh` |
| pr-downloader | `qant-au/pr-downloader` branch `macos-2026.09.02` at `f53a1366d4` | upstream's 2026.09.02 pin (`185cfba`, #70) + the macOS HTTP/1.1 fix for the BAR CDN, one commit; replaces the ExaDev fork | `.gitmodules` |
| BARb (skirmish AI) | `qant-au/CircuitAI` branch `macos-arm64-2026.09.02` at `bcc2173824` | upstream's 2026.09.02 pin (`f4a6ca3ae0`) + the AngelScript arm64 assembly in CMake, one commit (the const-operator half is upstream as #141); forked from the original port's `benbreen/CircuitAI` | `.gitmodules` |
| macOS floor | **27.0** (since 2026-11-08; was 26.0) | KosmicKrisp needs Metal 4 (26.0+); raised to 27.0 by maintainer decision | `MACOSX_DEPLOYMENT_TARGET` in `scripts/build-*.sh` and `packaging/release-build.sh` (also `LSMinimumSystemVersion`); engine, driver and bundle builds fail on any other `minos` |
